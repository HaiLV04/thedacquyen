# CHỌN THẺ ĐẶC QUYỀN 3D - Magic Privilege Cards 🎴✨

Ứng dụng web 3D tương tác mô phỏng giao diện bốc thẻ ma thuật trên màn hình Smart TV / máy chiếu lớp học, được đóng gói hoàn chỉnh trong **1 file HTML duy nhất**.

---

## 🚀 Công nghệ sử dụng
- **Three.js (r128)**: Xây dựng không gian 3D, hệ thống 800 hạt ánh sáng (Particles), thẻ bài 3D, vòng xoay ma thuật và `Raycaster` tương tác.
- **GSAP (GreenSock)**: Điều khiển hoạt ảnh bay xoáy lốc 3D (Vortex Orbit), lật thẻ 360 độ và chuyển cảnh mượt mà.
- **Tailwind CSS**: Thiết kế giao diện điều khiển HUD Glassmorphism hiện đại.
- **Canvas-Confetti**: Hiệu ứng pháo giấy chúc mừng rực rỡ khi lật thẻ.
- **Web Audio API**: Bộ tổng hợp âm thanh đa tầng (Synthesizer) tích hợp sẵn, không phụ thuộc file MP3 ngoài.

---

## 🎮 Cách sử dụng
1. Mở trực tiếp file `index.html` bằng bất kỳ trình duyệt web nào (Chrome, Edge, Safari, Firefox,...).
2. Bấm **"⛶ TOÀN MÀN HÌNH"** để trình chiếu trên TV hoặc máy chiếu lớp học.
3. Bấm **"▶ BẮT ĐẦU"** để kích hoạt xoáy ma pháp, sau đó bấm **"🛑 DỪNG"** hoặc click chuột / chạm tay trực tiếp vào 1 lá bài đang bay.
4. Tùy chỉnh danh sách thẻ, biểu tượng, độ hiếm hoặc tải ảnh thẻ mới trong mục **"⚙ QUẢN LÝ THẺ"**.
